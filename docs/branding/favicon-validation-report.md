| Fichier | Format | Dimensions | Transparence | Statut |

## Contrôles

- PNG lisibles et dimensions exactes : confirmé.
- favicon.ico contient bien 16, 32 et 48 px : confirmé.
- Icônes opaques sans pixel transparent : confirmé pour apple-touch-icon.png et maskable-512.png.
- SVG vectoriel valide, formes pleines uniquement : confirmé.
- maskable-512.png : contenu centré dans une marge de sécurité compatible avec un masque circulaire ou arrondi.
- Aperçus des masques : maskable-preview.png.
